# 내가 왕이 될 상인가?

서울·경기 세 단지를 비교해 **단지 자산총액 왕**과 **전용 평당가 왕**을 고르는 학습 게임입니다.
쉬움·어려움, 5판 100점, 브라우저 기록 저장과 기록 이미지 공유를 제공합니다.
[게임·데이터 안내](./about.html)에서 계산 방법과 데이터의 한계를 확인할 수 있습니다.

## GitHub Pages에 올리기

1. 이 배포 묶음의 **내용물 전부**를 별도의 public 저장소 루트에 올립니다. `index.html`이 루트에 있어야 합니다. 숨김 파일 `.nojekyll`도 포함하세요.
2. GitHub 저장소의 **Settings → Pages → Deploy from a branch**에서 업로드한 브랜치(예: `main`)와 **/(root)**를 선택하고 저장합니다.
3. Pages에 표시된 공개 주소에서 게임·안내 페이지를 확인합니다. 프로젝트 경로 아래에서도 작동하는 상대 경로를 사용합니다.

서버 코드·API 키·빌드 의존성은 필요하지 않습니다. 이 묶음에는 HTML, CSS, JavaScript, 마스코트와 게임에 필요한 선택 데이터만 들어 있습니다.
기존 분석 프로젝트의 저장소나 Git 이력을 옮기지 말고, 이 묶음을 별도 저장소에 복사하세요.

현재 공유 주소는 `https://nobot-kang.github.io/apt-king/`입니다. 다른 주소를 쓴다면 `records.mjs`의 `GAME_URL`을 실제 Pages 주소로 바꾸세요. 이미지와 복사 문구 모두 이 값을 사용합니다.

[GitHub Pages 공식 설정 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 로컬 확인

이 폴더를 작업 디렉터리로 사용해 Python 3가 설치된 환경에서 실행합니다.

```sh
python3 -m http.server 9034 --bind 127.0.0.1
```

`http://127.0.0.1:9034/`를 여세요. `file://`로 직접 여는 방식은 지원하지 않습니다.
온라인 서비스는 정적 파일만 제공하므로 Python 서버를 배포할 필요가 없습니다.

## 데이터와 기록

공개 데이터는 게임용 추정가격·단지 특성·계산 근거만 포함합니다. 원본 거래 목록, 분석 DB, 모델 파일은 포함하지 않습니다.
교육용 추정치이며 현재 시세나 투자 수익을 보장하지 않습니다. 정적 게임 특성상 문제 데이터와 정답 계산은 다운로드 가능한 파일에 들어 있습니다.
점수·시간은 브라우저에 저장되며 서버 검증 순위가 아닙니다. 배포 도메인이 바뀌면 기존 기록이 자동 이전되지 않습니다.

`release-manifest.json`은 이 묶음의 파일 목록·크기·SHA-256입니다. 업데이트할 때는 최신 묶음으로 파일을 교체하고, 최신 목록에 없는 이전 게임 파일은 제거하세요.
